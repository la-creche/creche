# crèche

A control plane for agents that run in deny-by-default microVMs. One file
defines an agent family, and the plane converges the host to that file.

The source is public. The deployment it was built for is private, and so are
its docs until they are rebuilt here.

- Issues are off, and pull requests from forks are not accepted.
- Security reports: `SECURITY.md`.
